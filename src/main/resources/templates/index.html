Características PWA Implementadas

SSR con Thymeleaf

El contenido es renderizado directamente en el servidor (Spring Boot) antes de enviarse al cliente, mejorando el SEO y la carga inicial.

Persistencia JPA

Uso de Spring Data JPA con H2 Database para la gestión del catálogo. El repositorio abstrae todas las operaciones CRUD.

Soporte Offline

El Service Worker intercepta las peticiones de red e implementa estrategia Network-First con fallback a caché para funcionamiento sin conexión.

API de Geolocalización

Acceso a la API nativa del navegador para obtener las coordenadas GPS del dispositivo con manejo de errores y permisos.

Instalable (Manifest)

El manifiesto Web define metadatos, íconos y modo standalone, permitiendo instalar la PWA como app nativa en el dispositivo.

App Shell Architecture

La estructura del shell (navbar, layout) está cacheada por el Service Worker, garantizando carga instantánea en visitas posteriores.
